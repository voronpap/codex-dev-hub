# Web, Tools and MCP

## Search / research
- **SearXNG** — self-hosted metasearch.
- **Perplexica** — self-hosted Perplexity-style research/search; engine/reference implementation.
- **Jina Search** — free-cloud search candidate.
- **Brave Search API** — monthly free-credit candidate.
- **Exa** — free allowance candidate.
- **Tavily** — agent/research search free allowance candidate.
- **SerpAPI** — smaller free allowance candidate.
- **Firecrawl search** — credits may join search pool.

Potential routing: free cloud search APIs -> SearXNG/local -> paid only by policy.

## Extraction / crawling / scraping
- **Jina Reader** — cheap/free URL-to-clean-content first path.
- **Crawl4AI** — strong self-hosted AI-friendly crawler.
- **ScrapeGraphAI** — prompt-driven extraction/crawl and source-adapter discovery/generation ideas.
- **Firecrawl** — cloud/open search/scrape/crawl.
- **Firecrawl Web Agent** — autonomous web research/extraction direction.

Escalation principle: simple fetch/Reader -> crawler/extractor -> browser.

## Browser
- **Browser Use** — agent/browser automation.
- **Cereon Browser Operator** — MCP/CDP control of real logged-in Chrome; validate security/maturity.
- **Playwright** — deterministic foundational browser automation.

## Desktop/computer use (future/high-risk)
- **UI-TARS Desktop / Agent TARS** — visual GUI agent.
- **Microsoft UFO/UFO2** — Windows UI Automation/Win32/visual agent.
- **Pan-Agent** — lightweight desktop-agent/node idea.
Useful for legacy software without APIs; must be tightly permissioned.

## MCP / A2A / discovery
- **Agentgateway** — centralized MCP/A2A/model gateway candidate.
- **MCP Gateway & Registry** — registry/discovery/security concept for MCP servers, agents and skills.
- **MCPGateway/progressive disclosure** — important idea: discover a capability first, load detailed tool schema only when needed.
- Dev Hub still exposes its own curated MCP surface to Codex.

## Sandbox/execution
- Docker/containers — baseline V1.
- **Nightona** — sandbox direction related to earlier open Daytona code; validate maintenance/security.
- **Daytona** — re-evaluate current source/licensing/product model before selection.

Sandbox goals: isolated worktree/filesystem, scoped network, resource/time limits, explicit secrets, disposable environment, artifact export.
